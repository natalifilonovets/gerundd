# Puppy Grammar

Адаптивна HTML-вправа на герундій та інфінітив із мультяшним песиком.

- 21 завдання, по одному за раз.
- Два варіанти відповіді та миттєве пояснення українською.
- Підсумковий результат і повторення помилок.
- Працює без інтернету: відкрийте `index.html` у браузері.

Усі стилі, JavaScript та зображення вбудовані в один файл. Збірка й залежності не потрібні.
